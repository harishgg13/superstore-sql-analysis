📊 Superstore Sales Analysis (SQL Project)
---

🔹 Objective
---
Analyze sales data using SQL to uncover insights related to revenue, profit, customer behavior, and regional performance.

🔹 Dataset
---
Superstore dataset containing:
Row_ID, Order_ID, Order_Date, Ship_Date, Ship_Mode, Customer_ID, Customer_Name, Segment, Country, City, 
State, Postal_Code, Region Product_ID, Category, Sub_Category, Product_Name, Sales ,Quantity, Discount, Profit

🔹 Key SQL Concepts Used
---
Aggregations (SUM, AVG, COUNT)
Grouping (GROUP BY, HAVING)
Window Functions (ROW_NUMBER, RANK)
Subqueries
Data filtering and sorting

🔹 Key Business Questions Solved
---
Total sales and profit analysis
Top products and customers
Regional performance comparison
Profit margin by category
Average order value analysis
Loss-making products identification

🔹 Key Insights
---
Certain regions generate higher average order value
High discounts often lead to negative profit
A few customers contribute significantly to total revenue
Some products consistently generate losses
Profit margins vary significantly across categories

🔹 Recommendations
---
Optimize discount strategies
Focus on high-margin products
Improve retention of high-value customers
Analyze loss-making products for removal or improvement

🔹 Files Included
---
SuperStore.sql → All SQL queries
Superstore_sales_analysis.pdf → Final business insights
